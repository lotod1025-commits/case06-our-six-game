인터랙티브 추리 게임 모음 | CASE 01 · 02 · 05 · 06

이 폴더는 ChatGPT Sites와 분리해 배포할 수 있는 정적 웹사이트입니다.
cases.html에서 네 사건을 선택할 수 있고, index.html은 CASE 06의 기존 주소를 유지합니다.
hyang-night, last-curtain, last-shutter 폴더에는 각각 잔향의 밤, 막이 내리기 전, 마지막 셔터의 게임 본체와 이미지가 있습니다.
폴더 구조를 그대로 유지해 올리면 실행됩니다.
방문자는 로그인 없이 게임을 플레이할 수 있습니다.

각 게임의 진행 상황은 플레이한 브라우저의 저장 공간에 따로 자동 보관됩니다.
같은 기기와 브라우저에서 다시 접속하면 이어서 플레이할 수 있습니다.
기기 간 자동 동기화는 제공하지 않습니다. '처음부터' 버튼으로 수사 기록을 초기화할 수 있습니다.

배경음악은 선택 사항이며 YouTube 동영상을 불러옵니다. 음악을 이용할 수 없어도 게임은 진행됩니다.
게임 본체는 ChatGPT 계정이나 서비스에 연결되지 않습니다.

GitHub Pages에 올릴 때는 이 폴더의 내용물을 저장소 최상위에 놓고,
저장소 Settings > Pages에서 main 브랜치의 /(root)를 게시 대상으로 선택하세요.
GitHub 계정이나 저장소가 삭제되면 해당 게시 주소도 사라집니다.
